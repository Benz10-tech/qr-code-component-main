### What I learned

Was able to properly create a custom root for the project and apply it using the style-guide:

```css
:root {
  --primary-color: blue;
  --background-color: hsl(212, 45%, 89%);
  --text-color: hsl(218, 44%, 22%);
  --accent-color: hsl(216, 15%, 48%);
  --font-size: 1.25rem;
  --font-family: "outfit", sans-serif;
  --font-weight: 400;
  --font-weight-bold: 700;
  --white: hsl(0, 0%, 100%);
  --width: 100%;
  --border-radius: 15px;
}
```
